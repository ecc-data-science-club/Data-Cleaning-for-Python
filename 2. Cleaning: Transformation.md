# Transforming Data For Cleaning

## Drop duplicates
```sh
# Drop exact duplicate rows across all columns
df = df.drop_duplicates()
df = df.drop_duplicates(inplace=True)

# Drop duplicates based on specific key columns (keep first or last occurrence)
df = df.drop_duplicates(subset=["user_id"], keep="first")
```

## Replacing data in rows
```sh
# Fill all NaNs with a static value 
df["col"] = df["col"].fillna(0)

# Fill empty cells with a value in a certain column
df.fillna({“column”: value}, inplace=True)

# Fill with mean, median, or mode 
df["col"] = df["col"].fillna(df["col"].mean()) 
df["col"] = df["col"].fillna(df["col"].median()) 
df["col"] = df["col"].fillna(df["col"].mode()[0]) 
```


## Removing missing values
```sh
# Drop rows with ANY missing values 
df_clean = df.dropna() 
df.dropna(inplace=True)

# Drop rows where ALL values are missing 
df_clean = df.dropna(how="all") 

# Drop rows where specific columns have nulls 
df_clean = df.dropna(subset=["column_name"]) 

# Drop columns containing any missing values 
df_clean = df.dropna(axis=1) 
```


### Changing names
```sh
# Replace all white spaces in column names with ‘_’
Df.columns = (df.columns.str.replace(“ “, ‘_’)

# Rename specific columns 
df = df.rename(columns={"Old_Name": "new_name", "Age Years": "age"}) 

# Change case 
df["city"] = df["city"].str.title() 
df["code"] = df["code"].str.upper()
```

## Dealing with Whitespaces and other symbols
```sh
# Convert all column names to lowercase and replace spaces with underscores 
df.columns = df.columns.str.lower().str.replace(" ", "_") 

# Strip whitespace from all column titles
df.columns = df.columns.str.strip()

# Strip whitespace in every variable in the column
df["column"] = df["column"].str.strip()

# Convert all column names to lowercase and replace spaces with underscores 
df.columns = df.columns.str.lower().str.replace(" ", "_") 
```

## Dropping Columns or Rows
```sh
# Drop unnecessary columns 
df = df.drop(columns=["unwanted_col1", "unwanted_col2"]) 

# Drop specific rows by index 
df = df.drop(index=[0, 1, 2])
```
