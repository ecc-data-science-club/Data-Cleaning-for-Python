# Data Exploration

(Note: df is a variable name and can be replaced with any name you want)

Start with importing the data and exploring it. Ask yourself questions about the data and notice inconsistencies:
What columns are there?
What data do I need for my hypothesis?
What data types are there? 
Are there any column names that are not uniform to the rest?



## Import and Read CSV files using pandas library
```sh
import pandas as pd 
df = pd.read_csv("dataset.csv") 
```

## Import and Read JSON file
```sh
import pandas as pd 
df = pd.read_json('dataset.json')
```

## Dataset exploration

```sh
# Overview of dataframe structure, memory usage, and column datatypes 
df.info() 

# Summary statistics for numeric columns (count, mean, std, min, 25%, 50%, 75%, max) 
df.describe() 

# Summary statistics for categorical/object columns “O”
df.describe(include=["O"]) 

# View shape of dataframe (rows, columns) 
print(df.shape) 

# View first five rows and last few rows 
df.head(5) df.tail(5) 

# View column names and datatypes 
df.columns df.dtypes

# View a specific column
print(df[‘column’])
```

## Checking for missing values
```sh
# Total missing values per column
df.isnull().sum()

# Percentage of missing values per column
(df.isnull().sum() / len(df)) * 100

# Total missing values in the entire DataFrame
df.isnull().sum().sum()

# Filter rows that contain at least one null value
df[df.isnull().any(axis=1)]
```

## Checking for duplicate values
```sh
# Check for duplicate rows
print(df.duplicated())

# Check count of duplicate rows
df.duplicated().sum()

# View duplicated rows
df[df.duplicated()]
```
