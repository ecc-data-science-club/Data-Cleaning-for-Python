# Filtering data with Pandas

Data and rows may be technically accurate and usable but be logically wrong. Filtering is the next step to ensure that the data is logically sound.

```sh
# Keep only realistic age entries (remove errors like age = -5 or age = 200) 
df = df[(df["age"] > 0) & (df["age"] <= 100)]

# Keep only entries where fire containment happened after fire alarm 


# Filter out test/internal accounts or cancelled transactions 
df = df[df["account_type"] != "Internal_Test"]


# Keep only records where customer_id is not missing (dropping specific rows and not just whole columns)
df = df[df["customer_id"].notnull()]


# Keep only validated transactions 
df = df[df["status"] == "Completed"]


# Convert date column to datetime first (standardize date so that it can be ordered)
df['transaction_date'] = pd.to_datetime(df['transaction_date'])

# Filter out future dates (system errors where timestamp is in the future) 
today = pd.Timestamp.today() 
df_valid_dates = df[df['transaction_date'] <= today]

# Exclude internal test accounts or internal IP addresses (Blacklisting) 
exclude_emails = ['test@company.com', 'admin@company.com', 'demo@company.com']
df_real_users = df[~df['email'].isin(exclude_emails)]

# Filter support tickets mentioning specific issue keywords 
df_bugs = df[df['ticket_description'].str.contains('crash|error|bug', case=False, na=False)] 


# Filter out top and bottom 1% extreme values (Percentile Trimming) 
low = df['price'].quantile(0.01) high = df['price'].quantile(0.99) df_trimmed = df[(df['price'] >= low) & (df['price'] <= high)]
```
